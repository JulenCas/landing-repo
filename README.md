# Lunara Stories Landing (React + Vite)

## Instalar

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

## Estructura

- `package.json` con dependencias de React, Framer Motion y Lucide.
- Componentes JSX en `src/components`.
- Estilos por componente (`*.css`) y estilos globales en `src/styles.css`.
